# 招聘猫 🐱

[![Python 3.8+](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

> 自动追踪网站招聘公告，新通知即时提醒，格式化导出结果。

招聘猫是一款轻量级桌面工具，专为批量监控政府、高校等招聘网站而设计。它会定期抓取指定网站的招聘公告，自动对比历史数据，精准标出新增和消失的通知，并通过可视化界面展示结果。

## 功能特性

| 功能 | 说明 |
|------|------|
| 批量监控 | 从 TXT 文件导入或手动添加任意网站 |
| 智能抓取 | 识别包含招聘关键词的链接与公告 |
| 增量对比 | 与上次扫描结果对比，精准标出新增/消失通知 |
| 定时扫描 | 支持自定义间隔自动扫描，无需手动操作 |
| 可视化界面 | 现代化分栏 GUI，双击直接在浏览器打开链接 |
| 格式化导出 | 支持 Excel(.xlsx) 和 CSV 两种格式 |
| 一键打包 | 运行 `build.bat` 生成独立 exe，无需安装 Python |

## 截图

> 📸 程序主界面：左侧为网站列表与扫描控制，右侧为扫描结果、新通知、运行日志和报告摘要四个标签页。

## 快速开始

### 方式一：直接运行（需 Python 3.8+）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动程序
python main.py
```

### 方式二：打包为 exe

```bash
# 双击运行 build.bat，或在命令行执行：
build.bat
# 生成的 exe 位于 dist\招聘猫.exe
```

## 使用说明

1. **添加监控网站**
   - 点击 **导入 TXT** 按钮，选择事先编辑好的网站列表文件（每行一个 URL）
   - 或点击 **添加** 按钮手动输入单个网址
   - 参考 `示例网站.txt` 了解文件格式

2. **开始扫描**
   - 点击 **▶ 开始扫描**，程序逐个访问网站并提取招聘通知
   - 扫描期间可随时点击 **⏹ 停止** 中断

3. **定时扫描**
   - 在左侧面板选择扫描间隔（30 分钟 ~ 8 小时或自定义）
   - 点击 **启用定时扫描**，程序将按间隔自动执行扫描

4. **查看结果**
   - **扫描结果** 标签页：所有通知，🆕 绿色高亮为新增，🗑 红色为消失
   - **🆕 新通知** 标签页：仅显示本次新发现的通知
   - **报告摘要** 标签页：纯文本摘要，可一键复制
   - 双击任意通知行，可在浏览器中打开原链接

5. **导出数据**
   - 点击 **导出 Excel / 导出 CSV** 保存格式化结果
   - Excel 含「汇总」「新通知」及每站独立工作表

6. **历史数据**
   - 每次扫描结果自动保存至 `%APPDATA%\招聘猫\`
   - 点击 **打开数据目录** 查看原始 JSON 文件
   - 点击 **清空历史数据** 后，下次扫描将把全部通知视为新通知

## 常见问题

- **部分网站无法抓取？** 需要登录或有反爬限制的网站，程序无法自动绕过登录墙
- **SSL 证书错误？** 政府网站有时使用自签名证书，程序已自动忽略 SSL 校验
- **扫描结果为空？** 若页面为 JavaScript 动态渲染（SPA），静态抓取可能无法获取内容
- **扫描频率建议？** 建议不低于 30 分钟/次，避免对目标网站造成压力
